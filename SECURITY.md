# Security Policy

## Supported versions

Security fixes are applied to the latest version on the default branch. If you are using an older release, please upgrade to the latest available version before reporting a vulnerability.

## Reporting a vulnerability

Please report suspected security vulnerabilities privately and responsibly. Do not open a public issue or submit a pull request that discloses the vulnerability.

Use GitHub's private vulnerability reporting feature for this repository if it is available. If you cannot use that channel, contact the repository maintainers through the GitHub profile contact information and include:

- a summary of the issue
- steps to reproduce the problem
- the affected component or file
- the potential impact
- any suggested mitigation or proof of concept

Please avoid sharing details publicly until a fix is available.

## Disclosure process

We will review and validate reports as quickly as possible. Once a fix is ready, we will coordinate disclosure in a way that protects users while communicating the remediation clearly.
